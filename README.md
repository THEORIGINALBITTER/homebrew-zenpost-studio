# Homebrew Tap for ZenPost Studio

Install ZenPost Studio on macOS with Homebrew:

```bash
brew tap theoriginalbitter/zenpost-studio
brew install --cask zenpost-studio
```

Upgrade to the latest release:

```bash
brew update
brew upgrade --cask zenpost-studio
```

Uninstall:

```bash
brew uninstall --cask zenpost-studio
```

The installer places `ZenPost Studio.app` in `/Applications`.
